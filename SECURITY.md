# Reporting a problem with the theorem or artifact

Please use the disclosure channel published at:

https://linkanetwork.app/.well-known/security.txt

Do not include user data, credentials, private keys or production exploitation
details in a public issue. A mathematical counterexample, unsound assumption,
missing observation class, manifest mismatch or reproduction failure is in
scope. Public discussion is welcome after coordinated review when disclosure
could affect users.
